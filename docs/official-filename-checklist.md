# Official Test-Plan Filename Checklist

Required PDF rule: `{StudentID}_{ScenarioType}_{YYYYMMDD}`

- Load filename: ________________________________________________

Validation regex for k6 plan files: `^23127027_(Load|Stress|Spike)_[0-9]{8}\.js$`

Validation rules:

- Student ID is exactly `23127027`.
- Scenario type is exactly one of `Load`, `Stress`, or `Spike`, with matching case.
- `YYYYMMDD` is eight digits and is a valid calendar date; `.js` is the k6
  source extension and is not part of the PDF's naming stem.
- The date is the actual appropriate human-selected date; it is not predicted, backdated, or generated by AI.
- Each of the three scenario types appears exactly once.

Human action: from the reviewed internal entry points, manually create or rename
the three official `.js` plans in `performance/scenarios/`, using the actual
appropriate date. Do not change business logic while naming them. Fill the
three blank fields above and request validation before any official execution.
